# Defect Agent 

## Overview
The **Defect Agent** serves as the final step in the pipeline. It reviews all the test cases generated by the Test Agent, compares them against the original requirements, and gives us a final confidence score on whether the feature is ready to be deployed.

## Core Responsibilities
1. **Execution Analysis**: Reviews the live pass/fail results from the **Execution Agent**.
2. **Historical Context**: Fetches past failure rates and regression trends for each module from the `history.json` database.
3. **Risk Highlighting**: Flags tests that hit high-risk areas based on both code-level risk and historical instability.
4. **Deployment Verdict**: Outputs a 0-100 confidence score and a measurable Go/No-Go verdict via the **Deployment Verdict** component.

## Why We Built This
We built the Defect Agent to provide a quick, objective summary of release readiness. Instead of relying purely on a gut feeling about whether a feature is "done," this agent gives developers and PMs a measurable score based on test coverage and identified risks.
